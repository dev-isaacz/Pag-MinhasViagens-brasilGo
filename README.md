# Pag Minhas Viagens - BrasilGo
 
Página web desenvolvida com **HTML e CSS**, simulando uma interface de catálogo de viagens nacionais para entrega de projeto final no curso Transforme-se em Desenvolvimento Front-End (Serasa Expirence & Proa) , com foco em layout, organização visual e estilização de componentes.
 
## Tecnologias
 
- HTML5
- CSS3
  
## Funcionalidades
 
- Layout de página para exibição de destinos de viagem
- Estilização com CSS (cores, espaçamentos, tipografia)
- Estrutura responsiva da página

## Aprendizados
 
Projeto prático para reforçar:
- Organização de layout com HTML semântico
- Estilização com CSS 
- Boas práticas de estruturação de página
